# 霓虹自律

一个赛博粉紫风的自律应用：记录作息、每日待办、爱好探索。全部数据保存在本机浏览器，不上传。

## 各标签页
- **今日**：大时钟 + 随时间切换的背景；记录入睡/起床（点「最近 7 天」可展开并补录）；管理每日清单（未完成的事项会自动滚到第二天）。
- **探索**：开启一个想探索的事物，每天打卡「今日投入」、写心得，随时「结束」并写复盘与结论，结束后进入「已结束归档」。
- **统计**：连续坚持天数、本周/本月完成数与完成率、睡眠近 7 天、每日计划完成率、探索坚持天数。
- **设置**：导出 / 导入数据备份。

## 数据安全
- 数据存在浏览器本地（localStorage），**不会上传**到任何服务器。
- 清理浏览器数据、换手机前，请先在「设置 → 导出备份」保存一份 `.json` 文件，之后可「导入恢复」。

## 在 iPhone 上使用（添加到主屏幕）
1. 用手机 Safari 打开部署后的网址。
2. 点底部「分享」按钮 → 「添加到主屏幕」。
3. 以后点主屏幕上的图标即可像 App 一样打开，支持离线使用。

## 本地预览
```bash
cd "项目目录"
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署上线（二选一）
- **Netlify Drop（最简单）**：打开 https://app.netlify.com/drop ，把整个项目文件夹拖进去即可得到一个网址。
- **GitHub Pages**：把项目上传到 GitHub 仓库，Settings → Pages 选择 main 分支并保存，得到 `https://用户名.github.io/仓库名/`。
