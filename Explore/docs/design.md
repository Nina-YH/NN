# 设计规范（Design）

## 风格定位
赛博黑客风 · 偏女性向 · 简洁高级。克制发光、柔和渐变、毛玻璃质感，避免堆砌。

## 配色
| 用途 | 色值 |
|------|------|
| 背景深紫黑（主） | `#0d0618` |
| 背景深紫黑（卡片） | `#1a0b2e` |
| 霓虹粉（主强调） | `#ff5ca8` |
| 霓虹粉（亮） | `#ff6ec7` |
| 霓虹紫 | `#a855f7` |
| 霓虹紫（亮） | `#b26bff` |
| 点缀青（数据/强调，少量） | `#7df9ff` |
| 文字主色 | `#f5eaff`（近白带紫） |
| 文字次级 | `#a58bc4` |

## 字体
- 正文：现代无衬线（系统字体栈 `-apple-system, "PingFang SC", sans-serif`）。
- 时间/数字/数据：等宽字体 `ui-monospace, "SF Mono", Menlo, monospace`（黑客感）。

## 质感与组件
- **毛玻璃卡片**：半透明深紫底 + `backdrop-filter: blur` + 细边框（`rgba(181,130,255,0.18)`）。
- **霓虹发光**：强调按钮/数字用 `box-shadow` 粉紫 glow。
- **圆角**：卡片 18–24px，按钮 12–16px，克制统一。
- **按钮**：主按钮霓虹粉渐变 + 发光；次按钮描边半透明。

## 四档时间背景
| 时段 | 背景 | 氛围 |
|------|------|------|
| 清晨 05:00–08:00 | 淡粉 → 淡紫晨光渐变，柔和上升光 | 温柔苏醒 |
| 白天 08:00–17:00 | 明亮通透的粉紫基调 | 清新 |
| 傍晚 17:00–20:00 | 夕阳紫粉暖调 | 温馨 |
| 夜晚 20:00–次日05:00 | 深底 + 霓虹粉紫星空/光晕 | 静谧 |

统一叠加赛博元素：细网格线、柔和扫描线、漂浮粒子，动画轻缓不刺眼。

## 布局
- 单页，底部固定 4 Tab：今日 / 探索 / 统计 / 设置。
- 手机优先，内容区最大宽度约 480px 居中。
- 安全区适配（`env(safe-area-inset-*)`）适配 iPhone 全面屏与灵动岛。
