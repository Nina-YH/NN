# 开发需求（Requirements）

## 产品概述
「霓虹自律」是一款个人自律工具，帮助用户记录作息、管理每日待办、养成/探索习惯，
并通过可视化统计获得坚持的成就感。视觉风格为赛博黑客风、偏女性向（霓虹粉紫）。

## 目标用户与设备
- 用户：个人使用，非技术背景。
- 设备：iPhone 17 Pro Max，Safari 浏览器，支持「添加到主屏幕」。
- 运行形态：网页应用（PWA），无需 App Store。

## 功能需求

### F1 睡眠记录
- 手动打卡入睡、起床两个时间点。
- 支持补录：忘记打卡时，可补填任意日期的入睡/起床时间。
- 自动计算当晚睡眠时长。
- 展示最近 7 天睡眠时长。
- **验收标准**：点击「入睡」记录当前时间；点击「起床」记录当前时间并算出时长；可修改历史某天时间；时长计算正确。

### F2 时间背景
- 根据系统当前时间自动切换背景，分为四档：清晨 / 白天 / 傍晚 / 夜晚。
- 背景含赛博元素（网格、扫描线、粒子），动画轻缓。
- **验收标准**：修改系统时间后背景在四档间正确切换，视觉连贯。

### F3 每日清单
- 添加事项、打勾完成、删除事项。
- 每天自动重置（新的一天清单为空，历史完成情况保留用于统计）。
- 显示「今日已完成 x / 共 y」。
- **验收标准**：增删改正常；跨天后清单重置、历史数据仍可用于统计。

### F4 打卡统计
- 连续坚持天数（定义：当天完成 ≥1 件清单，或记录了睡眠）。
- 本周 / 本月完成率（已完成项 / 总项）。
- **验收标准**：统计数字与录入数据一致，跨天、跨周计算正确。

### F5 探索模块
- 开启一个「探索」（输入名称、可选目标/理由、起始日期）。
- 进行中可每日打卡「今天投入了」+ 可选写一句话心得；可自由写长文本进展/感受（按日期）。
- 可随时「结束探索」，写「复盘」（过程回顾）与「结论」（是否继续/学到什么/最终判断）。
- 结束后归档，可回看；进行中显示投入天数、连续天数、心得数。
- **验收标准**：开启→打卡/心得→结束→复盘+结论→归档全流程可用，数据正确保存与回看。

### F6 数据备份
- 一键导出全部数据为 JSON 文件。
- 一键导入 JSON 文件恢复数据。
- **验收标准**：导出文件完整；清空后导入可完整恢复。

## 非功能需求
- UI 简洁不复杂，但高级好看（赛博黑客 + 女性向 + 霓虹粉紫）。
- 数据本地持久（localStorage）。
- 离线可用（PWA，service worker）。
- 单页应用，底部 4 个 Tab：今日 / 探索 / 统计 / 设置。
