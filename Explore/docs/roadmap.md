# 执行步骤 / 路线图（Roadmap）

> 增量推进：一次只做当前阶段，完成并验证通过后再进入下一阶段。
> 每阶段固定流程：开发 → 本地自测 → 更新 DEV_LOG.md → 进入下一阶段。

| 阶段 | 内容 | 验收标准 |
|------|------|----------|
| 0 | 项目初始化：CLAUDE.md + docs/ 五文件 + DEV_LOG.md | 文件齐备、内容完整 |
| 1 | 最小可运行骨架：index.html + styles.css + app.js 空数据层 | 浏览器打开能看到霓虹粉紫首页框架 + 底部 4 Tab |
| 2 | 睡眠记录：入睡/起床打卡、补录、时长计算、近 7 天列表 | 打卡/补录/时长正确，数据刷新后仍在 |
| 3 | 每日清单：添加/打勾/删除、每日自动重置 | 增删改正常，跨天重置、历史保留 |
| 4 | 时间背景：四档背景 + 赛博粒子/扫描线动效 | 改系统时间背景在四档间正确切换 |
| 5 | 探索模块：开启→打卡+心得→结束→复盘+结论→归档 | 全流程可用，数据正确保存与回看 |
| 6 | 打卡统计：连续天数、本周/本月完成率卡片 | 统计数字与录入数据一致 |
| 7 | 数据备份：导出 JSON / 导入恢复 | 导出完整，清空后导入可恢复 |
| 8 | PWA + 部署：manifest + service worker + 图标 + 托管上线 | iPhone 添加到主屏幕、离线可用、数据持久 |
